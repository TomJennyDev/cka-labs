  participant H as HPA controller
  participant M as metrics.k8s.io
  participant A as kube-apiserver

    H->>M: CPU hiện tại của các Pod web
    M-->>H: tổng millicore
    H->>H: % = dùng / request
    H->>H: mong muốn = ceil(hiện tại × % / 50%)

      H->>A: scale Deployment lên (≤ max)
    else giảm

      H->>A: scale xuống (≥ min)
    end
  end
